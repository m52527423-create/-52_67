# СтримСцена

Android-приложение для стрима игр с телефона на Twitch.

- Захват экрана телефона, звука игры (Android 10+) и микрофона.
- Редактор сцен: двигай и растягивай картинку игры, добавляй фото, баннеры и текст.
- Несколько сцен («Игра», «Скоро начнём», «Перерыв»), переключение прямо из шторки уведомлений.
- Стрим на Twitch по ключу трансляции (RTMP).

## Как устроено
- `app/src/main/assets/editor.html` — редактор сцен (WebView).
- `StreamService.kt` — захват экрана и отправка на Twitch (библиотека RootEncoder).
- `PlaceFilterRender.kt` — ставит экран игры в нужное место кадра.
- APK собирается автоматически в GitHub Actions при каждом изменении.
